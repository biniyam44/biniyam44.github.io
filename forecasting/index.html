02 / THE DECISIONS BEHIND THE CHART
A fair comparison
comes first.
The point is not to make the most elaborate forecast. It is to find out which approach is useful, what it misses, and whether the result can be reproduced.

      

        
01
Keep a simple model in the room.
A last-value forecast is a serious reference for prices. A seasonal naive forecast is useful when demand repeats. ARIMA, Prophet, and trees need to improve on those references, not just produce a smooth curve.

        
02
Only use what was available then.
Each forecast starts after the latest observation is known. Tree features use historical values, changes, rolling statistics, and, for the price series, historical volume. A same-row currency conversion of the target is not an independent feature.

        
03
Separate selection from measurement.
Validation chooses a model for each horizon. A later calibration period sets the empirical interval width. The final test period measures the frozen choices. During rolling evaluation, earlier test observations can become training history once their dates have passed; future observations never can.

        
04
Show uncertainty and the bad forecasts.
Intervals use errors from the calibration period rather than the test answers. Time series are dependent and can change regime, so nominal coverage is not assured. The explorer shows actual test coverage, interval width, and the largest misses.

      

    


    

      
03 / TWO DIFFERENT USE CASES
The question changes.
The checks stay.

      
CRYPTOCURRENCY PRICES
Can a model beat carrying the last price forward?
This study revisits a historical daily price dataset. It is an exercise in forecast evaluation, not an investable strategy. There are no transaction costs, execution assumptions, or trading returns in these results.
APPLIANCE ENERGY DEMAND
How predictable is a household's hourly appliance use?
This study uses public appliance-energy readings to examine short-horizon demand in kWh per hour. Ten-minute readings are aggregated into complete hours before modeling. Appliance consumption is not the household's total electricity load, and one household does not represent a utility or a commercial load portfolio.
