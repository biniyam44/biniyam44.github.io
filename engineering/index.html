Model lifecycle
Validation compares simple baselines with boosted trees. Calibration sets interval widths. Bundles carry file hashes and dependency versions. Promotion and rollback are explicit local operations; the API never accepts uploaded model files.
Bounded access
Protected routes require authentication. Request size, history length, and call rate are limited. Docker runs a single non-root process with a read-only model mount. A public deployment still needs managed secrets, TLS, and service-level monitoring.

    Evidence has limits
    The assistant can compare saved models, find their largest errors, and explain the documented methodology. It declines live predictions, missing experiment scope, secrets, and unsupported claims.
    Offline tests are not an LLM benchmark
    Fixed questions exercise numerical answers, citations, refusal, and mocked tool-planner responses. Real provider performance, latency, and cost remain unmeasured until a separately authorized API evaluation.
